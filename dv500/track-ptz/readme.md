* 描述

  * 本仓库解析目标坐标信息，输出云台 PTZ 运动控制指令，实现目标闭环追踪，并支持多种追踪工作模式
  * 推荐使用 ubuntu 18.04 工作
  * 使用者 clone 项目之后请创建新的工作分支


* 使用说明

  1. host 安装好目标平台对应的编译构建环境
  2. 添加依赖（执行一次）：cd fxEnv/ ； ./fxAddEnv.sh
  3. 编译程序：cd fxBuild ； cmake ..  -DFX_CHIP=2 ; make
     * FX_CHIP:  1: ss927 、2：dv500  // 默认为 1
